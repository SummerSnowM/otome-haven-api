Otome Haven API

Note: This API is specifically used for https://otome-haven.vercel.app only.

API Link: https://otome-haven-api.vercel.app

How to use: {API Link}/{Functions}

List of Functions are as follows:

Games

  • GET /games/:id - get all games by user id
  • GET /games/single/:id - get one game by game id
  • POST /games/:id - add a new game
  • DELETE /games/:id - delete a game by game id
  • PUT /games/:id - update game information by game id

Characters

  • GET /characters/:id - get all characters by game id
  • GET /characters/single/:id - get one character by character id
  • POST /characters/:id - add new character by game id
  • PUT /characters/:id - update character by character id
  • DELETE /characters/:id - delete character by character id

Game Ending Tracker: Chapters and Choices

  • POST /chapter/:id - add a new chapter by character id
  • POST /chapter/description/:id - add new description to chapter
  • PUT /chapter/description/:id - update description by character id
  • DELETE /chapter/:id/:chapter - delete specific chapter by character id

Game Ending Tracker: Routes

  • PUT /routes/:id/:endingId - update default route to a new ending

Game Ending Tracker: Endings

  • GET /endings/bestend/:id - get best ending by character id
  • GET /endings/badend/:id - get bad ending by character id
  • GET /endings/bffend/:id - get best friends by character id
  • GET /endings/normalend/:id - get normal ending by character id
  • GET /endings/gameoverend/:id - get game over ending by character id
  • GET /endings/unrequitedlove/:id - get unrequited love ending by character id
  • GET /endings/defaultend/:id - get default ending by character id
